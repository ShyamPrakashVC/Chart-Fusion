# Support

## Product

ChartFusion Power BI custom visual.

## Supported Version

Current certification build: `1.1.1.0`

## Support Channels

For support or bug reports, open a [GitHub issue](https://github.com/ShyamPrakashVC/Chart-Fusion/issues) or contact Shyam Prakash at `shyamsamsp@gmail.com`.

## Information to Include

When requesting support, include:

- ChartFusion visual version.
- Power BI Desktop or Power BI Service version.
- Browser name and version if the issue occurs in the Power BI Service.
- A screenshot or description of the issue.
- Field mapping used in the visual.
- Whether filters, RLS, or cross-highlighting are active.
- Console errors, if available.

Do not send confidential report data unless approved by your organization.

## Issue Categories

- Installation or import issue.
- Blank visual or missing field wells.
- Formatting pane issue.
- Incorrect totals or target-line behavior.
- Performance issue with large datasets.
- Accessibility or keyboard navigation issue.
- Certification or AppSource submission question.

## Response Targets

Response targets depend on the publisher's support process and service agreement. Define production response times before public release.
