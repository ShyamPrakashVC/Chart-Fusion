# ChartFusion Submission Description Guide

## Short Description

ChartFusion combines trend charts, matrix values, in-visual filters, totals, and formatting controls in one compact Power BI visual for faster KPI and trend analysis.

## Marketplace Description

Are your reports forcing users to compare separate charts, tables, filters, and totals before they can understand the trend?

ChartFusion brings trend charts, matrix values, in-visual filters, totals, and formatting controls together in one compact Power BI visual. It helps users analyze movement, compare categories, review exact values, and switch chart views without leaving the visual.

## Key Capabilities

- Combine chart and matrix table output in a single visual.
- Turn optional top filters on or off using Filter 1 and Filter 2.
- Show filters as dropdowns, checkboxes, bullet selectors, or timeline-style controls.
- Switch chart types live between Line, Clustered Bar, Stacked Bar, Lollipop, or No Chart.
- Add target/reference lines for goals, thresholds, averages, or benchmarks.
- Show or hide chart, table, totals, row headers, column headers, markers, and data labels.
- Customize labels, markers, colors, fonts, gridlines, borders, spacing, totals, and table layout.
- Use conditional formatting and total row/column options for clearer KPI comparison.

## Suggested Keywords

Power BI visual, combo chart, matrix table, KPI, trend analysis, lollipop chart, target line, in-visual filters, totals, conditional formatting.
