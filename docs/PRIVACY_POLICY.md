# Privacy Policy

Effective date: 2026-07-02

## Product

ChartFusion is a Microsoft Power BI custom visual.

## Summary

ChartFusion does not collect, store, sell, transmit, or share user data. The visual renders only the data that Power BI provides to it through the Power BI visual DataView.

## Data Processed by the Visual

ChartFusion may display:

- Category values assigned to `X-axis`, `Y-axis / Category`, `Filter 1`, and `Filter 2`.
- Numeric measure values assigned to `Values`, `Additional Row Values`, and `Add Target Line`.
- Optional tooltip fields assigned to `Tooltips`.
- User-selected formatting settings saved by Power BI as report metadata.

## Data Storage

ChartFusion does not store report data in browser local storage, session storage, cookies, IndexedDB, or external systems.

## Network Access

ChartFusion does not make external network requests. The visual does not use `fetch`, `XMLHttpRequest`, WebSocket APIs, or external telemetry endpoints.

## Telemetry

ChartFusion does not implement custom telemetry, tracking pixels, analytics beacons, or usage reporting.

## Microsoft Power BI Environment

Power BI may process data as part of normal Microsoft Power BI service and Desktop behavior. That processing is governed by Microsoft terms and policies, not by ChartFusion.
